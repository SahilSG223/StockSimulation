# Memory Arena (demo dashboard)

A replay viewer for the governed-memory experiment. Seven agent archetypes orbit
a living "market" blob; trades animate as lines into the centre, a timeline scrubs
through the run, and side panels show the equity race, the leaderboard, and the
five adaptation metrics. Toggle **No Memory / Raw Memory / Governed Memory** to
watch the same seed play out under each memory regime.

It visualizes the thesis directly: under **Governed Memory**, lessons learned in
the bull regime get **invalidated** after the regime flips (watch the toasts and
the red dots on the timeline), so stale influence and repeated mistakes fall — the
right-hand metrics panel and the equity lines tell the story.

## Run it

It's a static page, but it `fetch`es the replay JSON, so it needs to be *served*
(opening `index.html` over `file://` is blocked by the browser's CORS policy):

```bash
cd app
python3 -m http.server 8000
# open http://localhost:8000
```

Any static server works. Needs network on first load: the DC runtime
(`support.js`) pulls React 18.3.1 + Babel from unpkg (pinned, SRI-checked).

Controls: **Space** play/pause · **← / →** step · drag the timeline · hover an
agent for its decision card (portfolio, reasoning, memories fired, and the
counterfactual "what it would have done without memory").

## Files

| File | What it is |
| --- | --- |
| `index.html` | The Memory Arena component (authored in Claude Design as `Memory Arena.dc.html`). |
| `support.js` | The DC runtime that mounts the component (parses `<x-dc>`, compiles the bindings, loads React). Generated — do not hand-edit. |
| `replay-{none,raw,governed}.json` | Replay data, one per memory mode. |

## Where the data comes from

The replays are generated by the evaluation harness — **no numbers are authored
by hand or invented in the browser** (`.claude/rules/simulation.md`). Regenerate:

```bash
pnpm tsx src/evaluation/replay.ts          # writes src/evaluation/out/replay-*.json
cp src/evaluation/out/replay-*.json app/   # the viewer serves these copies
```

The schema is the Zod contract in `src/evaluation/replay-schema.ts` (the writer
fails closed on any mismatch). It is a self-contained document per run: contiguous
per-tick `frames`, each with every agent's authoritative snapshot (portfolio,
status, retrieved memories, counterfactual, and an optional trade `interaction`),
plus per-run `summary` metrics and the regime/event timeline.

Current demo: `regime_reversal`, **seed 31**, 100 ticks. Seed 31 (not the sim's
older seed 42, which stopped tripping governance after a trajectory change) is
where governed memory visibly earns its keep: ~13 lesson invalidations, stale
influence well below raw, equity at or above raw. The seed lives in
`src/evaluation/replay.ts`; re-scan if `SIMULATION_VERSION` changes.

## Not this

The separate 5-phase judge narrative (`DemoFrame` / `run-memory-demo.ts`, see
`docs/UI_PLAYBOOK.md`) is a different artifact with its own contract. Memory Arena
is the full multi-agent replay viewer on the `replay-<mode>.json` contract.
